Issue title:
简单的图书管理系统2

Issue body:
需求背景：
我要做一个简单的图书管理系统，用于管理图书的基础信息和库存状态。当前只需要实现最小可用版本，方便后续测试 AI 自动生成代码、接口、数据库和测试用例的能力。

目标：
支持图书的新增、查询、修改、删除，以及简单的借出、归还操作。

功能范围：
后端接口即可，暂时不做前端。

约束条件：

后端使用 Java Spring Boot。
数据库使用 MySQL。
提供 REST API。
图书编号或 ISBN 不能重复。
图书库存不能小于 0。
暂时不做用户登录和权限控制。

验收标准：

可以新增图书。
可以查询图书列表。
可以根据图书 ID 查询图书详情。
可以修改图书信息。
可以删除图书。
可以借出图书，借出后库存数量减少 1。
当库存为 0 时，借出失败。
可以归还图书，归还后库存数量增加 1。
ISBN 重复时，新增失败。
有基础测试用例。
