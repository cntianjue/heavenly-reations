Issue 内容：
标题：
[Feature] 简易计算器模块

需求背景：
我要实现一个简易计算器，用于支持用户完成基础四则运算，包括加法、减法、乘法、除法。

目标：
支持用户输入两个数字，选择运算符，点击等号后返回计算结果，并支持清空和基础异常处理。

功能范围：
实现基础计算器逻辑即可，可包含简单页面或后端接口。第一版只支持两个数字之间的一次运算，暂不支持复杂表达式、括号、历史记录、科学计算。

约束条件：

支持加法、减法、乘法、除法。
除数不能为 0。
连续输入运算符时，只保留最后一个运算符。
点击清空后，输入内容和结果恢复为初始状态。
第一版只支持如下计算格式：数字1 运算符 数字2 =。

验收标准：

用户可以输入数字。
用户可以选择 +、-、×、÷ 四种运算符。
用户点击 = 后可以得到正确计算结果。
用户点击 C 后可以清空当前输入和结果。
输入 8 ÷ 0 = 时，系统提示 不能除以 0 或返回 Error。
输入 1 + 2 = 时，结果为 3。
输入 5 - 3 = 时，结果为 2。
输入 4 × 6 = 时，结果为 24。
输入 8 ÷ 2 = 时，结果为 4。
系统有基础测试用例，覆盖加减乘除、清空、除以 0。
